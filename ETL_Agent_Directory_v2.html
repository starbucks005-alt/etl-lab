Ratings are suggestions based on each agent's skill and personality. Sources: the ETL Master Reference, the emerging-tech-lab.com agents page and the ETL roster. Several names appear on more than one platform and are listed once. A backpack is live tool access. Backpack status comes from the ETL roster (roster.json), the roster of record. The note on each row says what that agent reaches. The rows corrected on 2026-10-11 were checked against the running code and, where it could be done, by a live test; the rest follow the roster.

Voice data was added 14 October 2026 from the code and config files of Good Company, the ETL roster, Newswire, The Dose, The Gym, Everly Castle, Gandhi-King Center and Greylander Press, plus the Voice column of ETL_Agent_Roster.xlsx. "Not found" means no voice turned up in the files scanned, not that none exists. Not yet scanned: My Echo clients, the OPSEC Gauntlet chamber judges (voice fields exist but no IDs are set) and the Founder Studio PA pool.
