Build Your Own Agent

The workshop bench.

Start with a blank bench and walk out with a fully specified staff member: purpose, reach, name, story, personality, face, and voice. Every agent built here follows the house rule: verify before you believe.

Looking to alter or dress an existing persona instead? That is Chris's Tailor Shop, next door. This bench builds new ones from scratch.

1. What kind of agent?

Start with the job. What does this agent do, and who is it for?

2. Reach: backpack or in-framework?

Same skills, different reach. A backpack gives the agent its own live tools that travel across platforms. In-framework agents use whatever the host site provides.

MCP Backpack
Carries its own live tools (web, data, registries). Travels across sites. For agents that make factual or safety claims needing live verification.
In-Framework
Uses the host site's tools and fact-checker. For craft, role-play, and host personas that do not need live lookups.

Each maps to a live data server. CC wires the adapters and keys on deploy.

3. Name and tagline.

Give the agent a name and a one-line hook.

4. Background and story.

Where they come from, how they got here, what shaped them. This is the backstory the agent carries.

5. Personality and voice.

How they talk and what makes them them. This drives the chat tone and the watercooler banter.
