Full Transparency

What it costs to run this lab.

This is not a static website. Every agent conversation, every course video, every voice response calls a live API in real time. Here is the full monthly stack.

Service What it does Per month
Anthropic API Powers every agent conversation across the campus, now including Mission Possible Spy Academy ~$800
Netlify Hosting and serverless functions for all campus sites ~$230
HeyGen AI avatar video for all courses; no slides, no lectures $149
ElevenLabs Voice synthesis for agents, courses, and audio briefings $99
InVideo AI AI video generation for content and social $120
Supabase Auth, database, and all member data $25
Vimeo Video hosting for all course content $12
Domains + DNS All ETL campus properties ~$15
DigitalOcean Real-time broadcast feed server ~$6
Monthly floor ~$1,456

Not listed: Stripe processing (2.9% + $0.30 per transaction). Mission Possible Spy Academy has moved off Kajabi and onto this campus, so that $200 now runs through the Anthropic line rather than leaving the total.

Lab Member subscriptions fund this infrastructure directly. Every paying member reduces the share Dr. O carries and keeps these tools free for students who could not access them otherwise.
